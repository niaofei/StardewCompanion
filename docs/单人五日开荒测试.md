# 单人五日开荒测试

开发专用模式：由脚本控制单人房主，创建全新的 `SC5D_时间戳` 农场。普通房主仍禁止受控；只有显式设置 `SC_SOLO_TEST=1`、角色 `SC5Host`、对应测试农场且非联机时，才允许此例外。测试夹具不进入发布包。

构建游戏模组、Diagnostics 和 Fixture 后运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start-solo-five-days.ps1
```

启动脚本在 `.local/solo5/<runId>/Mods` 中隔离模组，启动无模型调度的诊断服务，再通过原版新建存档流程开局。不会注入物品、作物、体力或日期。礼包、清障、锄地、播种、制作箱子均调用游戏原生交互或操作路径并检查实际效果。

每日流程：优先维护初始15格防风草，收集木材，够50木材后制作及放置工作箱，将允许的资源存入箱子；有余力时到巴士站采集，最后正常返家睡觉。第5天检查首批收获，第5夜写档后停在第6天早晨。不开矿、不钓鱼，也不包含商店交易或后续任务链。

证据文件：

- `status.json`：当前阶段、停止原因或五日完成结果。
- `script.jsonl`：每次任务的参数、真实回执、日终作物/背包和夜间存档位置、大小、时间。
- `decisions.jsonl`：程序已有的任务事件接口；脚本任务标记 `source=script`，模型规划关闭。
- `world.json`：夹具观测到的当前测试身份、日期与原生存档目录。

可用 `tools/watch-decisions.ps1 -SessionFile <本轮目录>/session.json` 监控任务流。会话文件包含本机认证令牌，勿随报告公开。脚本遇到失败会暂停执行，不修改游戏状态来跳过失败步骤。

单人连续换日成功不能替代多人同步验收，也不能证明模型自主规划已通过五日运行。
