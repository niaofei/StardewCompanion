# 十日自主测试

启动命令：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/start-solo-five-days.ps1 -Autonomous -Days 10
```

需要同时调试桌面前端时，加 `-DesktopFrontend`。测试 Agent 将由桌面程序承载，游戏以普通窗口模式启动；前端数据和原文 prompt 捕获保存在本次运行目录。测试结束后导出代表性真实请求：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/export-prompt-samples.ps1 -RunRoot .local/solo5/<本次运行目录>
```

脚本创建全新的 `SC10D_` 单人农场，沿用正常新建游戏流程，不预置物资、作物、体力或日期。启动时只向模型发送一次 `initial-instruction.txt` 中的一句话目标，再启用自主执行；观察脚本随后只读取状态，不派发劳动任务或追加策略。

第10夜正常换日保存结束、进入第11天且没有活动菜单和任务时，Agent 自动暂停。没有按现实运行时长、体力或游戏时刻接管劳动的阈值。

监控窗口可查看公开规划、工具参数和实际回执，也可发送玩家指令。点“暂停”后，单人测试角色恢复正常键鼠控制；点“继续”后交还 Agent。监控操作和玩家指令会记入日志，玩家手动操作造成的成果不能全部归因于模型。

当前测试记录由 `.local/solo5-current.json` 定位；每轮目录包含：

- `trial.json`：测试天数、运行标识和程序哈希。
- `initial-instruction.txt`：唯一初始任务。
- `decisions.jsonl`：模型输入、公开回复、选用工具、实际派发与回执、暂停及换日事件。
- `observation-snapshots.jsonl`：游戏时间、体力、生命、金币、背包、作物及箱子观察。
- `world.json`：隔离存档标识及原生保存路径。
- `autonomy-status.json`：观察脚本的当前阶段。

测试结束或手动停止后，再统一检查操作密度、格式错误、自我纠错、无效重复、实际消耗和真实成果。暂不使用钓鱼、挖矿、战斗模块；未完成原生验证的新增经营能力仍不会作为已验证工具向模型开放。
